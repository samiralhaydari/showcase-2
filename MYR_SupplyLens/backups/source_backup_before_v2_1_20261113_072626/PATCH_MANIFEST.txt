MYR SupplyLens V2.1 patch manifest
==================================

This archive contains source-code replacements, tests, documentation and a Colab
notebook. It does NOT contain or overwrite trained model weights, scalers, raw
data, processed data, SQLite records, or saved invoice/supplier records.

V2.1 creates a separate model-artifact family using _v2_1_ filenames. Existing
V2 and V1 artifacts remain available as backward-compatible inference fallbacks.
